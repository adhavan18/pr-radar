# Cypher queries

Generated by `python -m prgraph.gendocs` from `prgraph/queries.py`, `prgraph/algos.py`, `prgraph/agent/memory.py` and `prgraph/ingest.py`. Ids: PR/Issue `owner/repo#N`, File `owner/repo:path`, Repo `owner/repo`. Defaults: k=10, max_paths=3, min_overlap=0.5, min_jaccard=0.4.

## Question queries

### dup_shared_issue

Q1. Other PRs that fix/reference the same issue. Params: $pr.

```cypher
MATCH path = (p:PR {id:$pr})-[:FIXES|REFERENCES]->(i:Issue)<-[:FIXES|REFERENCES]-(o:PR)
WHERE o <> p
RETURN o.id AS other, o.state AS state, o.title AS title, i.id AS via, path AS evidence
ORDER BY o.created DESC
```

### dup_file_overlap

Q1. PRs touching >= $min_overlap of this PR's files.

```cypher
MATCH (p:PR {id:$pr})-[:TOUCHES]->(pf:File)
WITH p, count(pf) AS mine
MATCH path = (p)-[:TOUCHES]->(f:File)<-[:TOUCHES]-(o:PR)
WHERE o <> p
WITH o, mine, count(DISTINCT f) AS shared, collect(path) AS paths
WHERE toFloat(shared) / mine >= $min_overlap
RETURN o.id AS other, o.state AS state, o.title AS title, shared, mine,
       paths[0..$max_paths] AS evidence
ORDER BY shared DESC LIMIT $k
```

### dup_similar_title

Q1. PRs/issues in the same repo with title-token Jaccard >= $min_jaccard (size-filtered candidates).

```cypher
MATCH (p:PR {id:$pr})-[:IN_REPO]->(repo:Repo)
WITH p, repo, size(p.tokens) AS n WHERE n > 0
MATCH path = (p)-[:IN_REPO]->(repo)<-[:IN_REPO]-(o)
WHERE o <> p AND (o:PR OR o:Issue) AND o.tokens IS NOT NULL
  AND size(o.tokens) >= n * $min_jaccard AND size(o.tokens) * $min_jaccard <= n
WITH o, path, n, size(o.tokens) AS m, size([t IN o.tokens WHERE t IN p.tokens]) AS common
WHERE common > 0
WITH o, path, common, toFloat(common) / (n + m - common) AS jaccard
WHERE jaccard >= $min_jaccard
RETURN o.id AS other, labels(o)[0] AS kind, o.state AS state, o.title AS title,
       common, jaccard, path AS evidence
ORDER BY jaccard DESC, common DESC LIMIT $k
```

### issue_fixed_by

Q1 (issue form). Is issue $issue already being fixed?

```cypher
MATCH path = (i:Issue {id:$issue})<-[rel:FIXES|REFERENCES]-(p:PR)
OPTIONAL MATCH (a:Person)-[:AUTHORED]->(p)
RETURN p.id AS pr, p.state AS state, p.merged AS merged, type(rel) AS link,
       a.login AS author, path AS evidence
ORDER BY p.merged DESC
```

### reviewers

Q2. People who authored (1) or reviewed (2) PRs touching the same files; +3 per shared file. Bots (Person.is_bot) excluded.

```cypher
MATCH (p:PR {id:$pr})
OPTIONAL MATCH (me:Person)-[:AUTHORED]->(p)
WITH p, me
MATCH path = (p)-[:TOUCHES]->(f:File)<-[:TOUCHES]-(o:PR)<-[r:AUTHORED|REVIEWED]-(cand:Person)
WHERE o <> p AND (me IS NULL OR cand <> me) AND NOT coalesce(cand.is_bot, false)
WITH cand, count(DISTINCT f) AS files, count(DISTINCT o) AS prs,
     sum(CASE type(r) WHEN 'REVIEWED' THEN 2 ELSE 1 END) AS weight, collect(path) AS paths
RETURN cand.login AS reviewer, files, prs, files * 3 + weight AS score,
       paths[0..$max_paths] AS evidence
ORDER BY score DESC LIMIT $k
```

### impact

Q3. Files historically co-changed with this PR's files but not in it.

```cypher
MATCH (p:PR {id:$pr})-[:TOUCHES]->(f:File)
MATCH path = (f)-[c:CO_CHANGED]-(g:File)
WHERE NOT (p)-[:TOUCHES]->(g)
WITH g, sum(c.weight) AS strength, collect(path) AS paths
RETURN g.path AS file, strength, paths[0..$max_paths] AS evidence
ORDER BY strength DESC LIMIT $k
```

### impact_file

Q3 (file form). What breaks if $file changes: co-changed files, with the PRs that changed both as evidence.

```cypher
MATCH (f:File {id:$file})-[c:CO_CHANGED]-(g:File)
OPTIONAL MATCH path = (f)<-[:TOUCHES]-(p:PR)-[:TOUCHES]->(g)
WITH g, c.weight AS strength, collect(path) AS paths
RETURN g.path AS file, strength, paths[0..$max_paths] AS evidence
ORDER BY strength DESC, file ASC LIMIT $k
```

### stale_open_prs

Q4. Oldest open PRs and how many reviewers they got.

```cypher
MATCH path = (a:Person)-[:AUTHORED]->(p:PR {state:'OPEN'})-[:IN_REPO]->(:Repo {id:$repo})
OPTIONAL MATCH (rv:Person)-[:REVIEWED]->(p)
RETURN p.id AS pr, p.title AS title, p.created AS created, a.login AS author,
       count(DISTINCT rv) AS reviewers, path AS evidence
ORDER BY created ASC LIMIT $k
```

### last_merges

Q4. Most recent merges (empty/old = stalled).

```cypher
MATCH path = (a:Person)-[:AUTHORED]->(p:PR)-[:IN_REPO]->(:Repo {id:$repo})
WHERE p.merged IS NOT NULL
RETURN p.id AS pr, p.merged AS merged, a.login AS author, path AS evidence
ORDER BY merged DESC LIMIT $k
```

### reviewer_load

Q4. Review concentration (bus factor), bots excluded.

```cypher
MATCH path = (rv:Person)-[:REVIEWED]->(p:PR)-[:IN_REPO]->(:Repo {id:$repo})
WHERE NOT coalesce(rv.is_bot, false)
WITH rv, count(DISTINCT p) AS reviewed,
     count(DISTINCT CASE WHEN p.state = 'OPEN' THEN p END) AS open_reviewed,
     collect(path) AS paths
RETURN rv.login AS reviewer, reviewed, open_reviewed, paths[0..$max_paths] AS evidence
ORDER BY reviewed DESC LIMIT $k
```

## Graph algorithms

### key_maintainers

```cypher
CALL algo.pageRank(null, null) YIELD node, score
WITH node, score WHERE node:Person AND NOT coalesce(node.is_bot, false)
MATCH path = (node)-[:AUTHORED|REVIEWED]->(p:PR)-[:IN_REPO]->(:Repo {id:$repo})
WITH node, score, count(DISTINCT p) AS prs, collect(path) AS paths
RETURN node.login AS person, score, prs, paths[0..$max_paths] AS evidence
ORDER BY score DESC LIMIT $k
```

### connection

```cypher
MATCH (a) WHERE a.id = $a OR a.login = $a
MATCH (b) WHERE b.id = $b OR b.login = $b
WITH a, b LIMIT 1
CALL algo.SPpaths({sourceNode: a, targetNode: b, relDirection: 'both', maxLen: 6, pathCount: 1}) YIELD path
RETURN length(path) AS hops, path AS evidence
```

### bus_factor

```cypher
MATCH (me:Person {login:$person})-[:AUTHORED|REVIEWED]->(p:PR)-[:IN_REPO]->(:Repo {id:$repo})
WHERE p.created >= $since
MATCH (p)-[:TOUCHES]->(f:File)
WITH DISTINCT me, f
MATCH (h:Person)-[:AUTHORED|REVIEWED]->(q:PR)-[:TOUCHES]->(f)
WHERE q.created >= $since AND NOT coalesce(h.is_bot, false)
WITH me, f, collect(DISTINCT h) AS humans, count(DISTINCT q) AS prs
WHERE size(humans) = 1 AND humans[0] = me
MATCH path = (me)-[:AUTHORED|REVIEWED]->(:PR)-[:TOUCHES]->(f)
WITH f, prs, collect(path) AS paths
RETURN f.path AS file, prs, 0 AS remaining_humans, paths[0..$max_paths] AS evidence
ORDER BY prs DESC, file LIMIT $k
```

### bus_factor_files

```cypher
MATCH (q:PR)-[:IN_REPO]->(:Repo {id:$repo})
WHERE q.created >= $since
MATCH (h:Person)-[:AUTHORED|REVIEWED]->(q)-[:TOUCHES]->(f:File)
WHERE NOT coalesce(h.is_bot, false)
WITH f, collect(DISTINCT h) AS humans, count(DISTINCT q) AS prs
WHERE size(humans) = 1
WITH f, humans[0] AS owner, prs
MATCH path = (owner)-[:AUTHORED|REVIEWED]->(:PR)-[:TOUCHES]->(f)
WITH f, owner, prs, collect(path) AS paths
RETURN f.path AS file, owner.login AS only_human, prs, paths[0..$max_paths] AS evidence
ORDER BY prs DESC, file LIMIT $k
```

### ownership_clusters

```cypher
CALL algo.labelPropagation({nodeLabels:['Person','PR','File'], relationshipTypes:['AUTHORED','REVIEWED','TOUCHES']}) YIELD node, communityId
WITH node, communityId WHERE node:File AND node.id STARTS WITH ($repo + ':')
MATCH (q:PR)-[:TOUCHES]->(node)
WITH communityId, node, count(DISTINCT q) AS touches
ORDER BY touches DESC
WITH communityId, count(node) AS files, collect(node.path)[0..5] AS top_files
WHERE files >= $min_files
MATCH (h:Person)-[:AUTHORED|REVIEWED]->(q:PR)-[:TOUCHES]->(f:File)
WHERE f.id STARTS WITH ($repo + ':') AND f.path IN top_files AND NOT coalesce(h.is_bot, false)
WITH communityId, files, top_files, h, count(DISTINCT q) AS w
ORDER BY w DESC
WITH communityId, files, top_files, collect(h.login + ' (' + toString(w) + ')')[0..5] AS top_people
RETURN communityId AS cluster, files, top_files, top_people
ORDER BY files DESC LIMIT $k
```

### bridges

```cypher
CALL algo.labelPropagation({nodeLabels:['Person','PR','File'], relationshipTypes:['AUTHORED','REVIEWED','TOUCHES']}) YIELD node, communityId
WITH node, communityId WHERE node:File AND node.id STARTS WITH ($repo + ':')
MATCH (h:Person)-[:AUTHORED|REVIEWED]->(q:PR)-[:TOUCHES]->(node)
WHERE NOT coalesce(h.is_bot, false)
WITH h, communityId, count(DISTINCT node) AS files, collect(q)[0] AS sample
WITH h, count(communityId) AS clusters, toInteger(sum(files)) AS files, collect(sample)[0..$max_paths] AS samples
WHERE clusters >= 2
UNWIND samples AS s
MATCH path = (h)-[:AUTHORED|REVIEWED]->(s)
WITH h, clusters, files, collect(path) AS evidence
RETURN h.login AS person, clusters, files, evidence
ORDER BY clusters DESC, files DESC LIMIT $k
```

## Agent memory

### remember_finding

```cypher
MERGE (s:Session {id:$session})
ON CREATE SET s.started = $at
CREATE (q:Question {id:$qid, text:$question, answer:$answer, evidence:$evidence, at:$at})
CREATE (q)-[:ASKED_IN]->(s)
WITH q
OPTIONAL MATCH (n) WHERE ((n:PR OR n:Issue OR n:File) AND n.id IN $about) OR (n:Person AND n.login IN $about)
WITH q, collect(n) AS targets
FOREACH (t IN targets | MERGE (q)-[:ABOUT]->(t))
RETURN q.id AS question, size(targets) AS linked
```

### recall_about

```cypher
MATCH path = (s:Session)<-[:ASKED_IN]-(q:Question)-[:ABOUT]->(n)
WHERE n.id = $ref OR n.login = $ref
RETURN q.text AS question, q.answer AS answer, q.evidence AS evidence_ids,
       s.id AS session, q.at AS at, path AS evidence
ORDER BY q.at DESC LIMIT $k
```

## Ingestion (batched UNWIND, idempotent MERGE)

### load people

```cypher
UNWIND $rows AS r
MERGE (a:Person {login:r.login})
SET a.is_bot = r.is_bot
```

### load prs

```cypher
UNWIND $rows AS r
MERGE (p:PR {id:r.id})
SET p.number=r.number, p.title=r.title, p.state=r.state, p.created=r.created,
    p.merged=r.merged, p.closed=r.closed, p.url=r.url, p.tokens=r.tokens
WITH p
MATCH (repo:Repo {id:$repo}) MERGE (p)-[:IN_REPO]->(repo)
```

### load issues

```cypher
UNWIND $rows AS r
MERGE (i:Issue {id:r.id})
SET i.number=r.number, i.title=r.title, i.state=r.state, i.created=r.created,
    i.closed=r.closed, i.url=r.url, i.tokens=r.tokens
WITH i
MATCH (repo:Repo {id:$repo}) MERGE (i)-[:IN_REPO]->(repo)
```

### load authored

```cypher
UNWIND $rows AS r
MERGE (a:Person {login:r.login})
WITH a, r
OPTIONAL MATCH (p:PR {id:r.id}) WHERE r.kind = 'PR'
OPTIONAL MATCH (i:Issue {id:r.id}) WHERE r.kind = 'Issue'
WITH a, coalesce(p, i) AS t WHERE t IS NOT NULL
MERGE (a)-[:AUTHORED]->(t)
```

### load reviews

```cypher
UNWIND $rows AS r
MERGE (a:Person {login:r.login})
WITH a, r MATCH (p:PR {id:r.id})
MERGE (a)-[e:REVIEWED {state:r.state}]->(p)
SET e.at = r.at
```

### load touches

```cypher
UNWIND $rows AS r
MATCH (p:PR {id:r.id})
MERGE (f:File {id:r.fid}) SET f.path = r.path
MERGE (p)-[e:TOUCHES]->(f)
SET e.additions = r.add, e.deletions = r.del
```

### load fixes

```cypher
UNWIND $rows AS r
MATCH (p:PR {id:r.id})
MERGE (i:Issue {id:r.iid}) ON CREATE SET i.number = r.number
MERGE (p)-[:FIXES]->(i)
```

### load refs

```cypher
UNWIND $rows AS r
MATCH (p:PR {id:r.id})
MERGE (i:Issue {id:r.iid}) ON CREATE SET i.number = r.number
MERGE (p)-[:REFERENCES]->(i)
```

### load labels

```cypher
UNWIND $rows AS r
MERGE (l:Label {id:r.lid}) SET l.name = r.name
WITH l, r
OPTIONAL MATCH (p:PR {id:r.id})
OPTIONAL MATCH (i:Issue {id:r.id})
WITH l, coalesce(p, i) AS t WHERE t IS NOT NULL
MERGE (t)-[:HAS_LABEL]->(l)
```

### load cochange

```cypher
UNWIND $rows AS r
MATCH (a:File {id:r.a}), (b:File {id:r.b})
MERGE (a)-[e:CO_CHANGED]-(b)
SET e.weight = r.w
```
